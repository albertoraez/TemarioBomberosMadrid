# Temario Bomberos Madrid

App web para estudiar el temario de bombero/a conductor/a especialista del Ayuntamiento de Madrid (bases BOAM 9.919).

- **Hoy**: tarjetas cortas y preguntas al momento, con repaso espaciado.
- **Test**: preguntas de los temas elegidos, con penalización de 1/3 por fallo, y simulacro.
- **Temario**: los 35 temas; las tarjetas de cada tema se pueden leer como apuntes.

Contenido actual: temas 1, 2 y del 9 al 13. Funciona en móvil y PC y se puede instalar como app.
